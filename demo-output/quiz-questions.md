Pool **₦30,000**, **3 winners**, split **₦15,000 / ₦10,000 / ₦5,000** (the engine’s
3:2:1 weighting produces exactly this). Pacing **manual**, **20s** per question.
Every question has 4 options; the correct option is marked. Correct letters are
spread across A/B/C/D.

These same 11 questions now ship as a built-in **question bank** in the app:
Instructor → Create quiz → **Add from bank**.

## Notes before you go live

- **Q5 (investor):** Iyinoluwa Aboyeji is the only BMONI person in the options —
  the others are non-BMONI names, so there is no “all of them are backers” trap.
- **Q1 / Q2 (“my name” / “your name”):** these only play fairly if both hosts
  introduce themselves and the names stay on screen. Confirm exact spellings
  (“Godbless Ossu” vs “God bless Ossu”) — they show on the projector and in
  winner copy.
- **Q3 (“founded”):** BMONI publicly **launched in Nigeria in October 2025**; the
  public answer is **2025**. If you mean the BKEY Inc. incorporation date, swap
  the year — just make sure one option is unambiguously correct.
- **Q8 (“how long they worked on it”):** answer set to **2 years** (host-confirmed).
